# 手动目录用量统计

用户确认：移除文件数统计，关闭自动递归目录用量扫描，管理员通过刷新按钮发起统计。

- 文件系统容量和 inode 继续自动采集（statvfs）；原存储扫描周期改称磁盘容量采集周期，保持配置兼容。
- 页面 GET 与后台定时采集均不遍历目录。只有认证并通过 CSRF 校验的 POST /api/storage/refresh 发起后台扫描，记录审计。
- 存储、共享目录和账号详情复用刷新入口，显示上次目录统计时间、统计中及失败状态。并发请求复用当前任务，不重复扫描。
- 手动扫描保存目录字节用量，移除目录条目数及相关 inode 比例告警；保留文件系统 inode 告警。
- 不改动用户文件、账号权限或挂载配置。手动扫描仍可能产生较高 I/O，页面明确提示空闲时使用。

验证：覆盖 GET/定时任务不扫描、手动完成、并发去重、失败重试、时间戳不被容量采集刷新、认证/CSRF，以及中英文界面和移动端刷新流程。
