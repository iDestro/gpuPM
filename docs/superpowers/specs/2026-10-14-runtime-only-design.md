# 任务只设置最大运行时间

用户选择删除独立指定到期时间，任务编辑仅保留最大运行时间及现有到期动作。详情自动计算的deadline_at改叫预计结束时间，是只读信息。任务保存显式发送expires_at=null，清除旧独立期限，避免保存后仍被隐藏字段限制。后端字段暂留兼容旧记录/客户端，不迁移或自动修改服务器现有任务；未保存的旧记录保留原配置。时长从启动时刻算，留空不限时，版本/权限/审计行为保持。

验收：编辑无指定到期字段；带旧expires_at的任务保存后该字段为空，最终截止由started_at+max_runtime_seconds计算；详情显示预计结束时间；取消草稿不修改现有任务。
