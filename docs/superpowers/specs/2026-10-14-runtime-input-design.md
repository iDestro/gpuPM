# 最大运行时间输入

用户要求小时、分钟、秒输入和快速设置。任务编辑与全局默认最大时长共用duration字段：时/分/秒分开输入，快捷值30秒、1分钟、30分钟、1小时、4小时、24小时及不限时。小时可超过24，分秒0–59；空白/不限时发送null，显式0时长不允许。保留既有API秒值、10年上限、配置版本、未保存关闭确认，不改变后台期限语义。任务帮助文案说明从启动时刻计算。

使用已有AntD InputNumber/Button/Form；表单内部按时分秒存值，加载/保存时转换，旧值精确到秒保持。通过表单检查负数、非整数、分秒范围及总上限。快捷按钮触发正常字段变更，保存前仍是草稿。编辑弹窗居中并限制表单高度，内部滚动，小屏幕保持标题/关闭按钮可见。

验收：旧3661秒回显1时1分1秒；组合输入正确换算；秒/小时快捷、清空null、非法零/总上限拒绝；取消仍有确认；实机检查两个入口，不改变真实任务配置。
