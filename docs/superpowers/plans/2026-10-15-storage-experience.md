# 存储与团队共享专项整改

用户已确认整改审查中列明的问题。保留现有 React/AntD、FastAPI/root agent 架构，不新增依赖，不恢复磁盘配额，也不迁移或删除旧账号数据。

## 实施与验收范围

1. 存储页：按文件系统展示容量与使用率，清晰区分采样/过期状态；结构化告警与共享用量；用户搜索、账号生命周期筛选、用量排序与账号链接；原始诊断收起。
2. 共享页：项目/路径/组搜索、路径复制、主组和附属组成员展开、读写优先的只读成员去重；权限组不足引导；创建路径说明、同组拒绝、单一预览弹窗；采样时间与过期提示。
3. 后端：账号状态与共享采样时间进入统计；共享列表触发受锁保护的后台采样；旧结构缓存自动刷新。
4. 共享失败：ACL回读校验完整权限及默认继承；本次空目录创建失败时清理以允许重试。有文件或身份变化时保留数据、限制本次新目录访问并明确报错。编辑失败标记权限需重新验证并增加版本，避免继续宣称授权成功。
5. 测试：创建失败重试、文件/既有路径/替换目录保护、ACL不匹配、编辑失败、共享采样；前端搜索/状态/成员/引导；浏览器创建-预览-编辑-刷新-中英文-移动端；部署后的真实网页与Linux ACL验收。

## 边界

成员展示依据当前主组/附属组，并不枚举所有文件的有效权限；已有会话和文件 ACL 可能不同。异常退出或断电后的共享目录不自动删除；未知残留需管理员检查。验收账号仅软删除，文件保留。
