# Platform Internationalization Implementation Plan

> Use superpowers:subagent-driven-development and superpowers:dispatching-parallel-agents for isolated file scopes, then spec review followed by quality review.

**Goal:** 整个平台中英切换，中文必要术语hover显示专业英文。
**Architecture:** 无依赖语言store及三个固定文案目录；React订阅语言变化，AntD locale与展示格式同步。只翻译界面，不改原始数据。
**Tech Stack:** React19/AntD5、TypeScript、Vitest、Playwright。

- [x] 语言store/文案合并与偏好测试；默认中文及安全回退。
- [x] 页面及设置可读字段国际化，保留数据/权限/期限行为。
- [x] 导航、登录、语言选择器及AntD locale国际化。
- [x] 共用编辑/预览/终止、状态与术语提示国际化。
- [x] 先规格审查，再质量审查；中文全回归、英文各页/表单/记忆/术语/手机验证。
- [x] 两入口部署，实机无写入验收，文档/提交。
