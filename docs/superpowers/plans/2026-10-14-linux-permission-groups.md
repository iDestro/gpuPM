# Linux 权限组管理实施计划

用户已批准：平台聚焦人员账号及项目文件权限，默认不展示全部 Linux 系统组。

1. **后端分类与边界**：默认列表只返回受管普通权限组；支持其他只读组及完整列表。根据实际主组引用识别用户私有主组，human 为只读人员范围组，系统/敏感组保持只读。返回主组用户及共享目录引用，避免把没有附属成员误认为空组。
2. **启用管理**：复用变更预览、修订版本、一次性确认及审计流程；已有普通项目组可明确启用管理，仅保存管理记录，保留原有成员与 GID。禁止同时授权成员、重命名或纳入受保护组。
3. **授权范围**：账号及共享目录选择器只允许新选受管普通权限组。账号自己的私有主组和现有旧授权可保留，编辑其他字段不得意外移除现有关系。服务端同样校验，不能依赖页面过滤。
4. **界面与国际化**：侧栏及页面统一为 Linux 权限组；默认“受管权限组”，切换到“其他组（只读）”；明确显示类型、附属成员、主组用户与共享引用。私有主组归账号详情；human 解释用途。删除有任何引用的组不可操作。
5. **验证**：覆盖分类、只读保护、启用管理身份及预览检查、无系统命令副作用、账号和共享目录授权及旧数据保留。运行后端、前端单元及 Chrome 浏览器测试，分阶段审查。
6. **部署**：在 wzx-ubuntu 运行 Linux 测试；备份数据库后更新真实试用及演示服务，保持原生写操作关闭。只读核对真实系统组/账号/共享关系及网页，记录部署与测试结果。

不新增用户组删除策略、自动迁移组成员或 Linux 提权授权功能。
