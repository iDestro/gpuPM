# 已结束任务计时与服务主进程到期终止修复

根因已由原生日志与代码确认：API/host始终用当前时间计算运行时长，未保存结束时刻；终止目标把PPID=1一律当作未授权孤儿进程，误排除systemd启动的已确认主进程。此前5分钟fixture由systemd RuntimeMaxSec兜底退出，不能证明平台发出信号。

实施范围：
- 在共用残留生命周期处理中维护last_seen_at和首次采集确认的finished_at，host/API共用计时函数。已结束运行时间冻结，剩余时间无数据，overdue=false；没有结束时间的历史记录保持未知。结束时间表示采集确认时间，存在采集周期的误差。
- 只允许已确认leader identity匹配的PPID=1进程进入普通终止目标。其他孤儿进程仍需授权，残留进程不自动清理；保持UID、pidfd、维护账号、保护、白名单、心跳和版本校验。
- 演示模式预览与执行采用相同leader例外。修正主进程的orphan误报，详情展示采集确认结束时间。
- 用失败回归验证实际signal dispatch和冻结时间，再运行现有保护/残留/API/UI回归。实际GPU设置30秒平台上限，systemd仅在120秒兜底；要求policy审计明确记录目标PID的SIGTERM及exited，在多个采集周期后验证计时不变。

不迁移历史时间、不修改全局默认策略、不修改其他账号和任务配置。
