# 新任务默认策略

用户要求策略配置集中设置新任务默认值，例如最大运行时间30分钟、不保护。增加独立新任务默认策略分组：最大运行时间（初始1800秒，可不限时）、默认人工保护（false）、任务优先级（50，0–100）、到期动作（沿用notify）、已确认残留worker清理（false）。保留中英文及专业术语。默认值只在首次发现任务时复制，此后全局修改和服务重启不覆盖任务自身设置，仍可逐任务修改。

系统/服务/维护账号强制保护保持，其他账号只读范围保持。时限从进程启动时刻算；清理/终止仍遵守身份、范围、确认心跳和保护条件。全局值不是对已有任务的批量修改。旧配置新增字段补缺，原有最大运行时间（含null）、到期动作与其他值保留。新安装默认30分钟；本次两个试用入口通过API将新任务模板设置为30分钟/不保护/优先级50/残留清理关闭，不改已有任务。真实allow_mutations=false保持。

技术实现：纯domain默认常量/任务模板映射，数据库JSON缺省补全，SettingsPatch与root边界验证，新host发现复制模板、demo新种子任务用初始模板，旧demo/host记录不重置。前端仅新默认字段及分组，无新依赖。验证新/旧配置、新/旧任务、重启、强制保护、非法参数与中英文保存，实机默认值更新后旧任务身份/策略保持。
