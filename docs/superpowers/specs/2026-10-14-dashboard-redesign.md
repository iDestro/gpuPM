# Dashboard 排版整改

用户选择浅色、简洁的 GitHub 风格，要求修复长列表滚动后导航消失和长字符串挤占版面。参考 satnaing/shadcn-admin、tabler/tabler 的公开设计组织方式，继续使用现有 AntD，不增加 UI 框架依赖。

桌面：全屏固定高度框架，浅色分组侧栏和顶栏始终可见，主内容区单独滚动，侧栏菜单在短屏可独立滚动；导航由“资源监控、账号权限、存储协作、记录设置”分组。手机：收起桌面侧栏，通过有明确标签的按钮打开导航抽屉，选中页面后关闭并恢复焦点。

统一紧凑卡片/表格/筛选区，降低装饰与说明文本的权重。关键名称、状态、操作可见；路径、指纹、UUID、命令、原因和对象ID等按固定列宽截断，完整值可聚焦/悬停查看，详细内容通过展开行/详情保留。状态及已知审计操作中文化，未知值原样保留且不丢失。账号动作、PID/GPU身份和危险操作预览保持原权限和实际信息，详情不能截断关键核验内容。

验收：桌面长审计列表滚到末尾仍能看到菜单/顶栏；短屏导航全部可访问；375px无页面横向溢出、表格在自身区域横向滚动；长字符串不撑高表格行/挤掉动作；完整原因可展开、全部功能导航和安全操作流程保持通过。实机页面截屏检查后更新两个试用入口，账号数据和写权限不变。
