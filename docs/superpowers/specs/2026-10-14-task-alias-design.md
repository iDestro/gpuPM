# 任务别名与原始名称

用户已同意列表优先显示别名、悬停显示原始名称、详情展示两者。编辑字段改为任务别名，沿用name配置字段，避免迁移已有别名。新增只读original_name由agent保存，后续编辑、采样和结束均保留。旧host任务从已有GPU成员命令恢复（原命名规则截取120字符）；已结束且无成员的旧任务无法可靠恢复时标记未知。旧演示默认任务从固定种子名称恢复。列表复用CompactText，允许指定悬停文本，同时支持聚焦；详情完整展示原始名称。不改变身份、归组、优先级和终止逻辑，无新依赖。

验收：别名重复修改及agent重启不改变原始名称；host采样/结束保留；列表显示别名且tooltip显示原名；详情两者可见；既有保护和取消流程通过。
